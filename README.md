# Student Enrollment Form using JsonPowerDB

## Description
This project is a **Student Enrollment Form** developed using **HTML, JavaScript, Bootstrap, jQuery, and JsonPowerDB**.  
The application allows users to **add, fetch, update, and reset student records** using **Roll No as the primary key**.

JsonPowerDB is used as the backend database to store and manage student data efficiently without writing any server-side code.

---

## Benefits of using JsonPowerDB

- 🚀 **High Performance** – Faster than traditional databases
- 🧩 **Schema-free** – No need to define rigid schemas
- ⚡ **Serverless** – No backend/server setup required
- 🔐 **Secure** – Token-based authentication
- 📦 **Easy Integration** – Works directly with frontend via REST APIs
- 🧠 **Built-in CRUD APIs** – Reduces development time
- 💸 **Cost Effective** – Ideal for student projects and prototypes
